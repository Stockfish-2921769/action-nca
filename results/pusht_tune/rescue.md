# 按结果挑标签的数据（学生每次新 z / 新噪声闭环）

卡住的状态 = 彻底失败回合（最好覆盖率 < 0.5）里第一次卡住的时刻（之后 8、16 步推杆位移都 < 10 像素）。每个卡住的状态上，表里有数的规划器各接手 3 次（每次新 z / 新噪声，换随机数种子），跑到第 300 步；老师 = 同种子大 DP，小 DP、NCA = 同种子、只用示范训练的（dp_small、se_global），第九轮的小 DP、NCA = 同种子、补了第九轮数据的（dp_small_rescue、se_global_rescue，第十轮才用）。救出 = 整个回合的最好覆盖率 ≥ 0.5；每个规划器那一栏是它自己的几次里任一次救出；原来四个 = 第九轮的接手者（老师、老师 + 扰动、小 DP、NCA）。每个卡住的状态挑最好的一次（成功的里步数最少的，都没成功时最好覆盖率最高的），救出来的才留下：从接手到覆盖率最高的那一步，每一步一个样本，标签是实际执行的 16 个动作。示范共 25650 个样本，DART 数据每个种子约 3.6 万个。
